# Bundled media components

FRAMEVIEW uses libmpv for playback and FFprobe for media metadata.

- libmpv comes from the Windows x64 LGPL build of mpv revision [fe753a782461](https://github.com/mpv-player/mpv/tree/fe753a78246151a2489b472dabcb04f2edd61d50). See [the binary release and build details](https://github.com/zhongfly/mpv-winbuild/releases/tag/2026-11-12-fe753a7824) and the included libmpv license.
- FFprobe comes from the Windows x64 static LGPL build of FFmpeg revision [d838f9f9ae](https://github.com/FFmpeg/FFmpeg/tree/d838f9f9ae). See [the binary release and build details](https://github.com/FFmpeg-Builds/FFmpeg-Builds/releases/tag/autobuild-2026-11-12-15-40) and the included FFmpeg license.
- The libmpv wrapper is from [libmpv-wrapper v0.1.1](https://github.com/nini22P/libmpv-wrapper/tree/v0.1.1) and is covered by the included LGPL license.
